## Breaking change: Linear and Notion configuration on macOS

Linear and Notion configuration, including OAuth sessions and API keys, now lives in macOS Keychain instead of JSON files beside the binary. On first use, uni-cli migrates each existing service configuration to Keychain, verifies the copy, and removes the original JSON file. If migration fails or the Keychain entry conflicts with the file, the file is kept and the command reports an error.

Scripts that read or modify `linear.json` or `notion.json` must be updated. Custom MCP servers and Linux/Windows installations continue to use JSON configuration files. Results saved explicitly with `--save` remain in JSON files beside the binary. `LINEAR_API_KEY` continues to override the configured key without being saved.

## Slack improvements

- Wait for Slack's database lock to clear when it closes.
- Recover a private temporary copy when the cookie database needs recovery, leaving the original unchanged.
- Treat logging out without a saved session as a successful no-op.
